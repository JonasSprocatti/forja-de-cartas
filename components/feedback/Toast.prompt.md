**Toast** — transient feedback message with a brass border.

```jsx
<Toast type="ok">Carta salva!</Toast>
<Toast type="err">Não foi possível carregar a carta.</Toast>
```

`neutral` (brass), `ok` (green ✓), `err` (ember ⚠). In the app it slides up from the bottom-centre; here it's a static block you position yourself.
